# ReportBot v2 🤖📧

**Telegram Bot + Web Server برای گزارش‌دهی خودکار**

## ویژگی‌ها

✅ **ربات Telegram** برای ادمین‌ها:
- `/add` — افزودن گزارش (سابجکت + متن)
- `/list` — لیست کردن تمام گزارش‌ها
- `/delete` — حذف گزارش‌های انتخاب شده
- `/clear` — حذف تمام گزارش‌ها
- `/stats` — آمار گزارش‌ها
- `/link` — دریافت لینک صفحه گزارش‌دهی

✅ **صفحه وب** برای کاربران:
- هر بار **یک گزارش رندوم** انتخاب می‌شود
- باز کردن **Gmail App** (نه وب سایت)
- تشخیص خودکار دستگاه (اندروید، آیفون، کامپیوتر)
- دکمه‌های سریع برای ارسال گزارش

✅ **ذخیره‌سازی:**
- تمام گزارش‌ها در فایل `reports.json` ذخیره می‌شوند
- داده‌ها پایدار و بازیابی‌پذیر هستند

## نصب و اجرا

### ۱. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### ۲. تنظیم توکن ربات

فایل `bot.py` را باز کنید و این خطوط را تغییر دهید:

```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"  # توکن از BotFather
ADMIN_IDS = [12345, 67890]          # ID ادمین‌های تلگرام
```

### ۳. اجرای ربات و سرور وب

```bash
python bot.py
```

سرور وب بر روی `http://0.0.0.0:8080` اجرا می‌شود.

## استفاده

### برای ادمین‌ها (Telegram)

1. ربات را استارت کنید: `/start`
2. گزارش جدید اضافه کنید: `/add`
3. سابجکت را بفرستید (مثال: `URGENT: Doxxing Report`)
4. متن کامل گزارش را بفرستید (انگلیسی، با لینک‌ها)
5. گزارش ذخیره می‌شود! ✅

### برای کاربران (Web)

1. از لینکی که ادمین می‌دهد بروید
2. صفحه خودکار یک گزارش رندوم نمایش می‌دهد
3. دکمه **✉️ باز کردن Gmail** را بزنید
4. Gmail App باز می‌شود با گزارش آماده
5. فقط **Send** را بزنید! ✅

## تنظیمات

### گیرندگان ایمیل

فایل `bot.py` میں:

```python
GMAIL_TO = "abuse@telegram.org,reports@telegram.org,stopCA@telegram.org,dmca@telegram.org"
```

می‌توانید این ایمیل‌ها را تغییر دهید.

### پورت سرور وب

```python
WEB_PORT = 8080  # تغییر دهید اگر نیاز است
```

## مشکلات و حل‌ها

### ربات جواب نمی‌دهد
- توکن را بررسی کنید
- از BotFather توکن جدید بگیرید
- اطمینان حاصل کنید که اتصال اینترنت برقرار است

### صفحه وب لود نمی‌شود
- پورت ۸۰۸۰ باز باشد
- `python bot.py` در حال اجرا است
- سرور پاسخ می‌دهد: `/api/reports`

### Gmail App باز نمی‌شود
- اندروید: Gmail App نصب شده باشد
- آیفون: Mail یا Gmail App نصب شده باشد
- کامپیوتر: اپلیکیشن ایمیل پیش‌فرض تنظیم شده باشد
